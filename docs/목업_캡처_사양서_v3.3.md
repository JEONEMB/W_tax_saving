# WON 세금비서 목업 캡처 사양서

본문에 맞춘 목업 3개입니다. 제안서 안의 점선 박스(크기 고정)에 그대로 넣으면 페이지 배치가 바뀌지 않습니다.

## 리모콘 V2로 캡처하기

- 앱 오른쪽 위 **리모콘 V2 · 캡처**를 누릅니다. 직접 주소는 `/#capture/a`입니다.
- 왼쪽 리모콘에서 목업 ①/②/③의 **전체 화면 · 제안서용** 버튼을 선택하고 **PNG 저장**을 누릅니다.
- ①은 `WON-v3.3-a-all.png` (2080×710px), ②는 `WON-v3.3-b-all.png`, ③은 `WON-v3.3-c-all.png` (각 2080×470px)로 저장됩니다.
- 각 번호 버튼은 해당 패널 하나만 표시·저장합니다. Word 삽입에는 **전체 패널 이미지**를 사용하세요.
- 브라우저 크기에 맞춰 미리보기만 축소되며 PNG 출력 크기는 고정입니다. 리모콘·브라우저 UI·커서·스크롤바는 PNG에 포함되지 않습니다.
- 패널 간 흰 간격은 36px(300dpi 기준 약 0.3cm)입니다. PNG의 DPI 메타데이터 대신 Word에서 너비를 17.4cm로 지정하세요.
- V2는 **캡처 전용 고정 예시**입니다. 기존 체험의 저장 데이터와 독립적이며, 화면의 인증·납입·예약·손택스 버튼은 실제 업무를 실행하지 않습니다. 왼쪽 ‘기존 체험으로’로 돌아갈 수 있습니다.
- 사례 B의 ‘세금 효과는 같고’ 표현은 282,000원→162,000원 변화와 충돌하므로 아래 문구로 정정했습니다. 제안서 본문에도 같은 표현이 남아 있다면 함께 수정하세요.

## 공통 기준

| 항목 | 기준 |
|---|---|
| 해상도 | 300dpi 기준. 가로 17.6cm = **2,080px 이상**으로 저장 (현재 초안 캡처는 흐릿함) |
| 형식 | PNG, 패널 사이 흰 여백 약 0.3cm, 패널마다 상단에 번호와 제목 (예: "1 추가 공제 여력 확인") |
| 데이터 | 전부 가상 데이터. 실명·실계좌 금지. 계좌는 `1002-•••-0821 (가상)`처럼 표기 |
| 정리 | **마우스 커서 제거**, 브라우저 UI·스크롤바 제거 |
| 숫자 | 아래 표의 숫자와 **한 글자도 다르지 않게** (본문 표·각주와 대조됨) |
| 문구 | "국세 감소액"은 반드시 "최종 환급액 아님"과 함께 표기 |
| 상품명 | "우리 연금저축(가상)"처럼 중립적으로 표기. 펀드로 표기하면 "원금 손실 가능" 문구도 함께 넣어야 함 (기존 목업은 "연금저축펀드"와 "펀드 매수가 아니에요"가 충돌했음) |

## Word에 넣는 방법

1. 점선 박스 안의 회색 안내 문구 두 줄을 지웁니다.
2. 커서를 박스 안에 둔 채 **삽입 → 그림**으로 캡처본을 넣습니다.
3. 그림 서식에서 너비를 **17.4cm**로 맞춥니다 (박스 여백 고려). 행 높이가 고정돼 있어 그림이 박스보다 크면 잘리므로, 높이가 박스 높이 이하인지 확인하세요.
4. 점선 테두리가 남는 게 싫으면 **표 디자인 → 테두리 → 테두리 없음**을 선택합니다.
5. 넣은 뒤 **5쪽이 유지되는지** 확인하고 PDF로 저장합니다 (파일 → 다른 이름으로 저장 → PDF, "ISO 19005-1 규격(PDF/A)" 또는 "글꼴 포함" 옵션 권장).
